  ## B. Donor Implementations That Undo Merged or In-Flight Fixes

  The donor tree b9f114a3 contains extensive regressions and uncompilable code across its function
  implementations. Taking the donor's function bodies would revert 13 distinct bug fixes:

  ### 1. Bead 4.35 (Higher-Order Functions - any-of-all Inverted Logic)

  • Donor Location: b9f114a3:xacml-
  core/src/main/java/org/xacml4j/v30/policy/function/impl/HigherOrderFunctions.java:105-115
  • Reversion: Implements anyOfAll as a.stream().anyMatch(v -> allOf(context, ref, v, b).value()) (checks
  if there is an element in a that matches all elements in b).
  • Correct Spec Behavior: XACML 3.0 §A.3.12 requires that for every element y ∈ b, there exists at least
  one element x ∈ a such that f(x, y) = true. Lane g43 correctly implemented this as b.stream().allMatch(vb
  -> a.stream().anyMatch(va -> ...)). Donor reverts 4.35.

  ### 2. Bead 4.36 (RegExp Functions - Missing 2.0 Canonical Identifiers)
