  ### C. Unblocking Fixes for First Family (BooleanVal, IntegerVal)

  #### 1. Unblocking BooleanVal

  • Root Blocker: BooleanVal.java:32 extends Value.OtherValue<Boolean>, inheriting non-final field
  value` at line 108 and instance field type` at line 149.
  • Fix:
      1. Break inheritance from Value.OtherValue and Value.AbstractValue. Implement Value<Boolean> directly.
      2. Declare BooleanVal as a value record BooleanVal(boolean value) implements Value<Boolean>.
      3. Change component type from boxed java.lang.Boolean to primitive boolean for unboxed in-memory
      inlining.
      4. Implement getEvaluatesTo() as return XacmlTypes.BOOLEAN; without storing an instance field.
      5. Retain static factories BooleanVal.of(boolean) and BooleanVal.ofAny(Object, Object...), returning
      canonical TRUE / FALSE or direct instances (which are substitutable under JEP 401).


    public value record BooleanVal(boolean value) implements Value<Boolean> {
        public static final BooleanVal FALSE = new BooleanVal(false);
        public static final BooleanVal TRUE = new BooleanVal(true);

        public static BooleanVal of(boolean v) {
            return v ? TRUE : FALSE;
        }

        public static BooleanVal ofAny(Object v, Object... params) { ... }

        @Override
        public Boolean get() {
            return value;
        }

        public boolean booleanValue() {
            return value;
        }

        @Override
        public ValueType getEvaluatesTo() {
            return XacmlTypes.BOOLEAN;
        }
    }

  #### 2. Unblocking IntegerVal -> Int64 (Design D11, Task 9.3)

  • Root Blocker: IntegerVal.java:36 extends Value.OtherValue<Long>, inheriting non-final field
  value` at line 108 and superclass field type` at line 149.
  • Fix:
      1. Replace IntegerVal class with Int64 record per donor slice 5.4 / design D11.
      2. Declare Int64 as public value record Int64(long value) implements Value<Long>.
      3. Store unboxed primitive long value instead of boxed Long.
      4. Return XacmlTypes.INTEGER directly in getEvaluatesTo().
      5. Provide an IntegerVal type alias / adapter in xacml-core during the transition phase to avoid
      breaking external callers before group 9 refactoring lands.


    public value record Int64(long value) implements Value<Long>, Comparable<Int64> {
        public static final Int64 ZERO = new Int64(0L);

        public static Int64 of(long v) {
            return new Int64(v);
        }

        public static Int64 of(Number n) {
            return new Int64(n.longValue());
        }

        public static Int64 ofAny(Object v, Object... params) { ... }

        @Override
        public Long get() {
            return value;
        }

        public long longValue() {
            return value;
        }

        @Override
        public ValueType getEvaluatesTo() {
            return XacmlTypes.INTEGER;
        }

        @Override
        public int compareTo(Int64 o) {
            return Long.compare(value, o.value);
        }
    }
