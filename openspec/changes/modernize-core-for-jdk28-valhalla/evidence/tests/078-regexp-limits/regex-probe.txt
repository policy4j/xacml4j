Stand-alone probe, JDK 21.0.6 (Oracle GraalVM), 2026-10-07.
Each row: Pattern.compile(pattern).matcher(input).find() in its own thread, waited for at most 3 seconds.
Inputs: "a" x 40 + "!" for the patterns with a; "x" x 30 for (x+x+)+y.
Patterns are in java.util.regex syntax (\z is what the XACML "$" is rewritten to).

(.*a){20}\z      TIMEOUT(>3s)     3002 ms

Reading: on this JDK the textbook patterns return at once; (.*a){20}\z does not
return within 3 seconds. RegExpLimitsTest uses the XACML form "(.*a){20}$".

Third probe: the worst case that the repetition bound still allows. The weight is the
largest product of nested minimum counts, so repetitions next to each other do not add
up. Pattern: 700 times "(?:){1000}" inside "(?:...){1000}" (weight 1,000,000, length
7,010), input "". Result: true in 48 ms.

Reading: every construct compiles. Five of the seven are slower with the large count, so
they repeat an empty atom. Two rows show 0 ms for both counts; their groups hold an

probe repeats the class case with {0} in place of ?). "[]a{1000001}]" is one class. 26
groups with two zero-width alternatives each take two seconds on an empty input (2^26
paths).

Sixth probe (review rv087 round 3): counted quantifiers that stand next to each other.
Input "". Cap 8 s.

nested, 30,000 x 30,000 (reference)    (?:(?:){30000}){30000}       true 34 ms
next to each other, group              (?:){30000}{30000}           true 1 ms
next to each other, lazy first         (?:){30000}?{30000}          true 1 ms
next to each other, literal            a{0}{30000}{30000}           true 0 ms
three next to each other               (?:){30000}{30000}{30000}    true 0 ms

Reading: the nested reference returned in 34 ms although it stands for 9 x 10^8 empty
iterations, while 10^8 took 121 to 171 ms in the fifth probe. On this JVM the time of empty
repetitions is not proportional to their count. Times are therefore no proof of how a pattern
is read; the test scannerRulesAreTheRulesOfJavaUtilRegex shows the rules by what a pattern
matches. The repetition bound stays: 2^31 x 2^31 did not return in 3 s (second probe).
