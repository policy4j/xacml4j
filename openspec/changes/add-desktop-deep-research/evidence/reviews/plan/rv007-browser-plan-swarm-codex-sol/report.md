Findings, most severe first:

1. **HIGH — design.md:423, D10; :634, D13. Driver persistence bypasses filtering.** The candidate dependency automatically records console messages and saves downloads before the bridge can filter them. A hostile fixture can emit unrelated text through `console.error` before binding, or initiate an unsolicited download; the resulting file already violates the storage rule. See the pinned revision’s [handlers](https://github.com/microsoft/playwright/blob/9ec5d7fdb786c81ee5a4c642d8e19e7488a1fa84/packages/playwright-core/src/tools/backend/tab.ts#L201) and [disk writer](https://github.com/microsoft/playwright/blob/9ec5d7fdb786c81ee5a4c642d8e19e7488a1fa84/packages/playwright-core/src/tools/backend/logFile.ts#L89). **Change:** select or adapt a driver that disables automatic raw persistence and accepts downloads only during an armed, bound collection. Test the filesystem independently, including before binding and on errors.

2. **HIGH — design.md:382, D10. The lock does not constrain launch configuration.** The plan leaves child-process environment handling unspecified, while the driver accepts environment-provided configuration and executable initialization files. If inherited, a caller can set `PLAYWRIGHT_MCP_INIT_PAGE` to an existing hostile report and invoke an allowed command: the driver loads that file as code without changing its package or tool schemas. See [configuration](https://github.com/microsoft/playwright/blob/9ec5d7fdb786c81ee5a4c642d8e19e7488a1fa84/packages/playwright-core/src/tools/mcp/config.ts#L369) and [loader](https://github.com/microsoft/playwright/blob/9ec5d7fdb786c81ee5a4c642d8e19e7488a1fa84/packages/playwright-core/src/tools/backend/tab.ts#L168). **Change:** require a minimal child environment, absolute verified executable paths, and bridge-owned configuration; exclude Node loader/module-search overrides and MCP environment overrides. Add poisoned-environment fixtures. This execution boundary deserves an ADR.

3. **HIGH — design.md:529, D12. The atomic guard omits authorization state.** Its enumerated checks do not include the approved plan hash, selected sources/model, or account continuity inside activation. Attack: approve plan P; the page replaces it with P′ while retaining the address, control, composer and input count; Begin can pass the listed checks and start P′. **Change:** define action-specific synchronous guard tuples, including pending plan/question identity and applicable account, binding, mode, model and source evidence. Test programmatic plan/source changes without input events; post-action detection cannot retract a submission.

4. **MEDIUM — design.md:524, D12; specs/browser-research-session/spec.md:130. Older references are not automatically rejected.** Playwright preserves a reference while the element’s role and name remain unchanged. Taking snapshots A and B of the same control therefore does not make A’s reference stale, contradicting the proposed driver guarantee. See [reference allocation](https://github.com/microsoft/playwright/blob/9ec5d7fdb786c81ee5a4c642d8e19e7488a1fa84/packages/injected/src/ariaSnapshot.ts#L208). **Change:** enforce bridge-owned observation epochs and page/document identity; recheck region membership at mutation. Include same-reference reuse, reparenting, same-address reloads and target-tab closure.

5. **MEDIUM — design.md:421, D10; :529, D12. Fixed snippets lack a defined parameter channel.** The pinned [`browser_evaluate` schema](https://github.com/microsoft/playwright/blob/9ec5d7fdb786c81ee5a4c642d8e19e7488a1fa84/packages/playwright-core/src/tools/backend/evaluate.ts#L25) accepts function text and an optional element, but no separate argument for the expected hash, counter or binding. **Change:** specify an audited template with schema-checked serialized data, separately hash code and invocation data, and forbid asynchronous gaps inside the guard. Do not quietly introduce arbitrary script construction or derive expected values from page-controlled state.

Distinguish structural bootstrap fixtures from fixtures validated against later characterization.
