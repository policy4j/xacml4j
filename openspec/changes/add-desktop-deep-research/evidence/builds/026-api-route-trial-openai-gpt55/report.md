# Research Report: Using only public official OpenAI and Anthropic sources, compare ChatGPT Deep Research and Claude Research: available desktop interfaces, initiation, source control, and report export. Include dated citations.

## Scope and interpretation

I used **only public official OpenAI and Anthropic sources** and interpret “desktop interfaces” as **desktop web plus native desktop apps**. I interpret “source control” as user/admin control over which web, file, connected-app, or connector sources the research agent can use. Current-date basis: **October 10, 2026**.

## High-level comparison

| Area | ChatGPT Deep Research | Claude Research | Comparative read |
|---|---|---|---|
| **Available desktop interfaces** | Deep Research is a ChatGPT feature. OpenAI’s launch post dated **Feb. 2, 2025** said it was available first on ChatGPT web and would roll out to mobile and desktop apps within the month; OpenAI’s current Deep Research help page, updated **19 days before Oct. 10, 2026**, describes starting it directly inside ChatGPT. The new ChatGPT desktop app is available globally for **macOS and Windows** as of the **July 9/16, 2026** release notes, and Linux desktop is in public preview as of **Aug. 14, 2026**. ([openai.com](https://openai.com/index/introducing-deep-research/?region=united-states)) | Anthropic’s Claude Research help page dated **June 2, 2026** says Research is available to paid Claude users on **web, Claude Desktop, and Claude Mobile**. Claude Desktop itself is available on **macOS, Windows, and Linux beta**. ([support.anthropic.com](https://support.anthropic.com/en/articles/11088861-using-research-on-claude)) | Both have web + native desktop coverage. Claude’s official desktop OS list explicitly includes Linux beta; OpenAI’s ChatGPT desktop Linux support is explicitly **public preview** in release notes, while macOS/Windows are the main global desktop app surfaces. |
| **Initiation** | Start by typing **`/Deepresearch`**, selecting **Deep research** from the **+ tools menu**, or selecting it from the **sidebar**. ChatGPT may ask clarifying questions, then creates a **proposed research plan** that the user can review and edit before the run. ([help.openai.com](https://help.openai.com/en/articles/10500283-deep-research-in-chatgpt%EF%BC%89)) | Click the **“+”** button in the chat interface and select **Research**; a blue indicator appears and can be clicked again to disable. Anthropic also says the user can steer Claude by prompting “Claude, please use the research tool to…”. Web search must be turned on for Research to function. ([support.anthropic.com](https://support.anthropic.com/en/articles/11088861-using-research-on-claude)) | ChatGPT’s flow is more explicitly **task-plan-first**; Claude’s is more **mode/toggle-based** and can be steered by prompt. |
| **Source control** | Defaults include the **public web** and **uploaded files**. Users can choose websites/files; eligible connected apps are available when permissions and workspace settings allow. Users can go to **Sites > Manage sites** and either **restrict** research to entered websites/domains or **prioritize** those sites while still allowing full-web search. Users can interrupt an in-progress run to refine focus and adjust which sources it can access. Connected apps are **read-only** for Deep Research, and Enterprise/Edu RBAC plus connected-account permissions are respected. ([help.openai.com](https://help.openai.com/en/articles/10500283-deep-research-in-chatgpt%EF%BC%89)) | Research searches across the **web** and connected internal context such as **Gmail, Google Calendar, and Google Docs** when connected. Users can steer it to pull from a named internal source. Claude connected apps can be toggled off for a conversation or disconnected entirely; custom connectors can also be enabled/disabled per conversation. Anthropic warns that during Research, Claude can invoke connector tools automatically after approval, and recommends disabling tools that can take write actions. Local MCP servers are not currently invokable by Advanced Research. ([support.anthropic.com](https://support.anthropic.com/en/articles/11088861-using-research-on-claude)) | ChatGPT documents **explicit web-domain scoping** for Deep Research. Claude documents **connector/app controls** and prompt steering, but the official Research help page does **not** describe a Research-specific “restrict to these domains only” control comparable to ChatGPT’s Sites control. |
| **Report export** | Completed Deep Research opens in a fullscreen report view with **table of contents**, **sources used**, and **activity history**; reports can be downloaded in **Markdown, Word, and PDF**. OpenAI’s **May 12, 2025** release notes separately introduced PDF export via the share icon, with tables, images, linked citations, and sources. ([help.openai.com](https://help.openai.com/en/articles/10500283-deep-research-in-chatgpt%EF%BC%89)) | Claude Research produces cited answers/reports, but the official Research help page does not document a Research-specific one-click report export. Instead, Claude’s surrounding official features provide export paths: Claude Docs can be requested in any conversation and exported as **Word, PDF, Markdown, or Google Docs**; artifacts made from templates have export controls; Claude file creation can generate downloadable **.xlsx, .pptx, .docx, and PDF** files, with a **30 MB** per-file upload/download limit. Claude chat sharing creates a snapshot link; attached files and raw MCP tool-call data are not included. ([support.claude.com](https://support.claude.com/en/articles/16923645-get-started-with-claude-docs)) | ChatGPT has a **native Deep Research report export** workflow. Claude can export a research deliverable if the user turns it into a **Doc/artifact/file**, but that is an adjacent workflow rather than a Research-specific export documented in the Research help page. |

## Bottom line

**ChatGPT Deep Research is stronger on explicit research-workflow controls**: editable plan, domain restriction/prioritization, mid-run source adjustment, report activity history, and direct export to **Markdown / Word / PDF**. **Claude Research is strong on integrated, connector-based research** across web and internal context, with per-conversation connector controls and rich downstream document/file export via Claude Docs, artifacts, and file creation—but its official Research page does not document a one-click Research-report export or a domain-restriction control equivalent to ChatGPT’s **Sites > Manage sites**.
