## License headers (research Q2)

- `license:update-file-header` with the current 1.7 changes 1,741 files of a
  clean copy (`license-1.7-vs-tree.txt`), 1,693 of them vendored fixtures
  under `xacml-conformance-tests/src/test/resources/`. The build is safe today
  only because every documented command passes
  `-Dlicense.skipUpdateLicense=true`.
- 2.7.1 differs from 1.7 in 160 files (`license-1.7-vs-2.7.1.txt`); the
  sampled difference is whitespace: 2.7.1 writes ` *` where 1.7 writes ` * `
  on the empty lines of the header.
- Decision (design D5): upgrade to 2.7.1 and make skipping the default
  (`license.skipUpdateLicense=true` in the root POM); updating headers needs
  `-Dlicense.skipUpdateLicense=false`.
