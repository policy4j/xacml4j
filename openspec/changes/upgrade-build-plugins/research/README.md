### Q2. Does license-maven-plugin 2.7.1 rewrite the existing headers?

- Answer: yes, when the update runs; and 1.7 rewrites files too. A forced
  `update-file-header` in a scratch copy changes 1,809 files with 1.7 and 1,704
  with 2.7.1, most of them vendored conformance fixtures (evidence
  `tests/003-characterization-v2`). The change therefore makes the update
  opt-in (`license.skipUpdateLicense=true` in the root POM, design D5); a
  default build changes no file (`tests/002-gate-both-mavens`).
  The 2.x line requires `licenseName`
  (`https://github.com/mojohaus/license-maven-plugin/releases`, 2.x release
  notes, "licenseName is required (#607)", retrieved 2026-10-26); the root
  POM sets `license.licenseName` to `lgpl_v3`.
- Confidence: high (local observation on this tree).

### Q3. Does maven-jaxb2-plugin 0.15.3 generate the same sources?

- Answer: yes, apart from the two XJC header comment lines. Both versions generate
  the same 110 files (109 Java sources and `META-INF/sun-jaxb.episode`); every
  differing line is `This file was generated by the Eclipse Implementation of
  JAXB, v2.3.6` (0.15.1) or `v2.3.7` (0.15.3), or the `Generated on:` time.
  Evidence: `evidence/tests/003-characterization-v2` (generation),
  `evidence/tests/004-jaxb-compare-v3` (comparison with file lists).
- Confidence: high for this schema set (local observation, not a vendor claim).
