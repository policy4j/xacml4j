   - **Lookup verification**: Executes every `LookupQuery` against `session.repository()`.    - **Concurrent verification**: When `threads > 1` (from JMH `BenchmarkParams.getThreads()`), `PdpDecideBenchmark.setUp` (`:78`) and `PolicyStoreLookupBenchmark.setUp` (`:78`) call `fixture.verifyConcurrent(threads)`. ## Residual Risks

1. **Unverified custom `PolicyRepository.add` return path in `PolicyStoreLoadBenchmark.importXml`** (Minor #1): Built-in stores (`in-memory` and `snapshot`) both implement `PolicyRepository.add` identically to `StoreSession.load`, so built-in benchmark numbers are unaffected. A future third-party store that overrides `StoreSession.load` without implementing `PolicyRepository.add` could silently no-op during `importXml` until Minor #1 is addressed.
2. **Pre-populated read-only stores without `StoreCapability.LOAD`** (Minor #2): Third-party read-only stores must override `StoreSession.load` as a no-op (or validation check) until `PdpFixture.open` skips `session.load(policies)` when `StoreCapability.LOAD` is absent.
